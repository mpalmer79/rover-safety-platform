## Known limitations

- The platform is **not** safety-certified. This report demonstrates engineering verification discipline, not regulatory compliance.
- Scenarios run against the deterministic Python engine. End-to-end Gazebo / ROS 2 verification on a Jazzy host is documented in `rover_ws/tests/manual.md`; results from those runs are not captured automatically by this report.
- The wheel-slip-only scenario does not by itself reach `MISSION_DEGRADED` because the platform has no state estimator; the corresponding scenario combines slip with a co-occurring IMU bias to demonstrate the degraded mode honestly.
- Nav2 is integrated only via the velocity-clamp boundary node; full Nav2 lifecycle coverage is out of scope for Phase 3.
