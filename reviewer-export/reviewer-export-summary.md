# Reviewer Export Summary

_Generated by `rover_ws/tools/generate_reviewer_export.py`. The platform is **not safety-certified**; this export is engineering review material._

## What this export contains

- Programme health (per-discipline rollups + reasons + triggering artefacts).
- Trend series across replay quality, analytics scores, qualification counts, gate status.
- Drift findings with severity + description.
- Subsystem risk (counts + ranking; no causal claims).
- Gate history (pass / warning / failure / not_executed counts).
- Replay quality (per-incident score + bag/origin labels).
- Incident index (severity, outcome, evidence status).
- Requirement coverage (REQ-* ids + mapped tests/artefacts).

## What this export does NOT contain

- Live runtime evidence not already present in the upstream artefacts.
- Causal claims about source changes.
- Predicted future regression.
- Safety certification of any kind.

## How to read evidence origins

| Origin | Meaning |
|---|---|
| `scenario-evidence` | Static scenario fixture (deterministic engine output). |
| `runtime-evidence` | Static runtime evidence (no live bag). |
| `live-runtime` | Captured on a Jazzy host (per the runbook). |
| `bag-backed` | rosbag2 / MCAP artefact present alongside the incident. |
| `static-source` / `static-workspace` | Source-tree-only signal. |
| `unknown` | Origin unrecognised — treat conservatively. |

## Static-only and missing-bag evidence

Replay-quality rows record `static_only=true` when the incident is static-only and `missing_bag=true` when no bag artefact exists. Both flags are preserved verbatim across the export. Static-only never silently becomes bag-backed.

## How to use the notebook

Open `notebooks/reviewer_walkthrough.ipynb` in Jupyter or VS Code. No additional dependencies are required; pandas and matplotlib are imported behind guards. The notebook loads every CSV from `../csv/` and shows row counts + previews.

## Known limitations

- The platform is **not** safety-certified. The reviewer export is an engineering evidence packaging.
- The export is read-only with respect to upstream artefacts; it never invents data and never infers causality.
- Static-only evidence stays static-only across the export. Missing-bag stays missing-bag.
- When a source artefact is missing, the corresponding table is still emitted with zero rows; the manifest records the absence.
- The reviewer notebook loads CSV files from the neighbour ``../csv/`` directory using only the Python standard library (and pandas / matplotlib via optional guarded imports).
